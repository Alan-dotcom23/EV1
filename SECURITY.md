# 🛡️ Política de Seguridad de AstroBank

Nos tomamos la seguridad de nuestros usuarios de manera muy seria. Si descubres un problema de seguridad, por favor repórtalo inmediatamente.

## 📦 Versiones Soportadas

Actualmente, solo las siguientes versiones de la aplicación reciben actualizaciones de seguridad mediante *hotfixes*:

| Versión | Soportada | Notas adicionales |
| ------- | :-------: | ----------------- |
| v2.0.x  | ✅ Sí     | Versión estable actual. |
| v1.5.x  | ✅ Sí     | Soporte extendido hasta diciembre. |
| < v1.4  | ❌ No     | Obsoleta, por favor actualiza. |

## 🚨 Cómo reportar una vulnerabilidad

Por favor, **NO** crees un *Issue* público en GitHub para reportar vulnerabilidades, ya que esto podría exponer a nuestros usuarios.

1. Envía un correo electrónico detallado a: `security@astrobank.com`.
2. Incluye en tu correo:
   * Descripción del problema.
   * Pasos para reproducirlo.
   * Un bloque de código de ejemplo (si aplica):
   
   ```javascript
   const hack = bypassSecurity("payload");
Responderemos a tu reporte en un plazo máximo de 48 horas. Puedes leer más sobre buenas prácticas de reporte en OWASP.
